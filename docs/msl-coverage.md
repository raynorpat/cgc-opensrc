# Metal coverage audit

The 2026-09-08 hardening pass expands the initial 69-test corpus to **558 Metal
tests**, including **228 runtime tests** and **11 allocation-failure sweeps** covering **2248 allocation failure points**.
All pass in strict Apple-compiler/runtime mode on the host recorded in
[qualification](msl-qualification.md). Runtime counts include numerical renders,
pipeline-only witnesses and deliberate negative controls.

## Coverage matrix

| Acceptance area | Evidence |
| --- | --- |
| Numeric families and widths | `msl_coverage_type_*`: bool/int/uint/float/half/fixed, scalar and 2/3/4 lanes; Apple compilation and GPU values. Runtime double, long, narrow integers and nonsquare matrices reject. |
| Intrinsic allowlist | `msl_coverage_intrinsic_*`: scalar and 2/3/4-lane floating elementwise operations; dot, length, distance, normalize, boolean reductions, cross, reflect/refract, matrix mul/transpose and fragment derivatives. Signed abs has scalar/vector witnesses. |
| Shared catalog boundaries | `msl_coverage_reject_catalog_*`: integer min/max/clamp and vector-vector mul calls rejected by the existing frontend/catalog, rather than advertised as available Metal signatures. |
| Expressions and statements | Signedness, integer shifts, vector comparisons, overlapping swizzles, early returns, for/while/do, break/continue, branch and loop-condition effects, and literal emission. |
| Helper calls | Forward declarations, typed overloads, exact profile > stage wildcard > open in both stages, nested calls, scalar/array/swizzle/row out/inout, stable incrementing indices, aliases, unreachable unsupported helpers and recursion rejection. |
| Aggregates and matrices | Nested record/array copies, uniform-to-local array copies, 2x2/3x3/4x4 matrices, transpose, matrix multiplication, row/element access and updates, constructor evaluation order, selector aliasing, and row reads/stores/copy-back with side effects. |
| Interfaces | Canonical aliases, case and leading-zero suffixes; duplicate canonical identities; missing/wrong POSITION, invalid color/depth/system semantics; reversed varyings, flat integer interpolation and incompatible pipeline rejection. Explicit attributes reserve first; reordered named declarations keep the same ABI. |
| Exact limits | 16/17 attributes, 16/17 resource pairs, 4096/4112 uniform bytes in source fixtures. Target unit tests cover 64/65 user components because the allowed source semantics cannot express that many independent fields. Oversized array arithmetic is checked before multiplication. |
| Uniform/resource ABI | Independent exact metadata assertions for nested bool/half arrays, matrix stride, global/parameter shadowing, unused-global removal, reordered uniforms/resources/attributes, explicit slot reservation, no empty buffer, promoted defaults and round-trippable values. |
| Textures | 2D, all six cube directions, nonzero vertex/fragment LOD, helper chains and paired binding slots. Vertex implicit samples, projected/gradient forms and unsupported resource shapes reject; bias spelling absent from the catalog rejects in the frontend. |
| Target invariants | Invalid stages/types/symbols, recursive record shape, unregistered aggregate types, initializer/return mismatches, malformed swizzles/indexing/calls, nonwritable targets, loop control, duplicate interfaces/resources and overlapping/out-of-range uniform slots. |
| Failure handling | Every coverage rejection checks its exact source line/code, code and `-nocode`, preserved/absent output, no new temporary files, and no target text on stdout. Bad destinations and partial-writer injection must fail. |
| Ownership boundaries | `msl_structure_and_enum_inventory` checks frontend traversal/backend dependencies, all current Cg IR expression/statement enum values, production source reuse by the fault executable, and deliberately invalid checker specimens. |

The original hand-reviewed output goldens remain in `tests/msl/profile/`.
The additional **276 source fixtures** and independent expected pixels are
reproducibly generated by `tests/msl/coverage/generate.py`. Python is a developer
regeneration tool; CTest uses the checked-in sources and CMake manifest and does
not require Python for these Metal tests. Every positive source is compiled
twice for byte-identical output and passed to Apple's compiler. New numerical
expectations are mathematical constants, never generated by cgc.

## Bugs exposed and fixed

- Mixed-type compound assignments, declaration initializers and returns now
  retain required implicit numeric conversions in target IR.
- Matrix constructors materialize effectful arguments in source order; row
  reads evaluate effectful operands once. Row inout copy-back registers its
  generated row-write helper.
- Gradient texture overloads now reject with C6602 instead of silently dropping
  derivative arguments and emitting an implicit sample.
- Uniform/global out actuals now receive C6608 before copy-back can reach the
  internal verifier.
- Allocation failure during sampler semantic construction no longer reaches
  `strcmp` with a null pointer. Default-data allocation failure keeps the
  allocation diagnostic instead of becoming a capability rejection.
- Half/fixed defaults accept the float shape produced by constant folding.
- ABI comments include fragment input varyings and stable category ordering
  under declaration reordering. Golden changes were checked to affect only
  metadata lines.
- The target verifier rejects malformed storage, addressing, calls, types and
  interface/layout records before serialization. Layout arithmetic rejects
  malformed or recursively oversized aggregate shapes safely.

The test-only `cgc_msl_fault` executable compiles the same sources as `cgc`.
On Apple Clang it runs with AddressSanitizer. Allocation injection sweeps every
index until the first successful compile, covering both scratch validation and
emission for layout, textures, defaults, aggregate copies and matrix/call
side-effect paths. Each failed index must preserve the output sentinel, report
allocation failure and leave no new temporary output. The production executable
contains no environment-controlled fault injection. Leak detection is disabled
for this existing compiler's process-lifetime allocation model; memory access
checks remain enabled.

## Boundaries of the result

This audits the implemented Metal surface, not every possible program or
floating-point input. The full design also describes source forms the existing
frontend cannot represent: effectful logical operands reject with C1052,
componentwise matrix arithmetic with C1020, some catalog signatures with
C1101/C1102, and resource aggregates/returns/out formals with C1151–C1153.
Those are explicit negative tests, not backend successes. `register(...)`
syntax is rejected by the parser; numeric binding semantics reaching Metal
receive C6604.

Aggregate defaults beyond constant constructors, compound whole-row updates,
and more general matrix-selector producer groups remain outside the documented
initial contract. This pass does not change those language capabilities or
claim cross-platform qualification. See [compatibility](msl-compatibility.md)
for the current application-facing surface and hardware limits.
