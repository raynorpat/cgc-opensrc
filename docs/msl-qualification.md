### Original baseline and portability prerequisites

The unchanged revision cannot configure and build on this host:

- CMake registers two WGL smoke tests referencing a Windows-only target.
- C declarations are missing for `memset`, `lLowerForStmt`, `HlslStringsEqual`,
  `GlslIREnsureType`, `lCountInitializerElements`, `ExtractSimpleDelta`, and
  `GetConstIndex`; `union expr_rec` lacks a file-scope forward declaration.
- The scanner's infinity macro takes the address of a cast expression and
  aliases float storage through `long` (also unsafe for the 64-bit host ABI).
- An unsupported-statement counter increments a cast instead of the pointed-to
  integer; an ARB loop call passes `found` where `&found` is required.
- ARB integer limit checks lack `<limits.h>`.

Focused prerequisites fix those errors, use value comparisons with `FLT_MAX`
for float infinity detection, and guard the WGL registrations with `WIN32`.
The complete Release build then succeeds, with existing warnings still present.
These are build/portability prerequisites, not an MSL backend implementation.
There is **no executable pre-fix generic baseline** on this Mac to compare with.

### Generated output and GPU results

The final strict configuration registers 1611 tests: 1604 pass, the same three
baseline tests fail, and four existing GLSL tests remain disabled. All **624 MSL
tests pass with no skips**, with both `CGC_REQUIRE_METAL` and
`CGC_REQUIRE_METAL_RUNTIME` enabled.

The backend emits deterministic vertex/fragment MSL and ABI metadata from a
separate typed target module. Golden tests compile and link the actual generated
source with Apple tools. All four bundled shaders also create Metal pipelines.
Numerical offscreen tests cover arithmetic/control flow, uniform slot layouts,
arrays and records, matrices and row writes, helper copy semantics, globals,
host-applied defaults, half promotion, varyings, discard/depth, 2D textures, all
six cube directions, and nonzero fragment/vertex LOD. The runtime checks 16
interior pixels of an 8×8 RGBA32Float target against independent expected values;
representative results include matrix `(17,39,23,34)`, row write `(9,8,3,4)`,
layout `(7,16,26.5,1)`, and depth `0.25`.

Negative controls prove that wrong pixels, wrong source/status expectations,
invalid Apple source, stale artifacts, and incompatible stage interfaces are
rejected. Transaction tests preserve existing output on compiler failure.
This qualifies the agreed vertex/fragment subset; it does not prove every
possible source combination or floating-point input.

All eight final generic captures match the post-portability reference exactly
for stdout, stderr, and exit status. Builds use `SOURCE_DATE_EPOCH=1788889613`
to preserve the reference compiler's embedded build timestamp; no timestamp or
diagnostic text is stripped by the comparator. Evidence is saved in

the per-test artifacts under `build/validation/`.

### Repeatable commands

Run from this worktree:

```sh
cmake -S . -B build/validation -DBUILD_TESTING=ON -DCMAKE_BUILD_TYPE=Release \
  -DCGC_REQUIRE_METAL=ON -DCGC_REQUIRE_METAL_RUNTIME=ON
SOURCE_DATE_EPOCH=1788889613 cmake --build build/validation --config Release -j 8
ctest --test-dir build/validation -C Release -R '^msl_' --output-on-failure
ctest --test-dir build/validation -C Release --output-on-failure
cmake -DCGC="$PWD/build/validation/cgc" -DSOURCE_DIR="$PWD" \
  -DOUTPUT_DIR="$PWD/build/evidence/generic-new" \
  -DCOMPARE_DIR="$PWD/build/evidence/generic-baseline" \
  -P tests/capture_msl_baseline.cmake
cmake -DOUTPUT_DIR="$PWD/build/evidence/probes" -P tests/run_msl_probes.cmake
```

Omit `COMPARE_DIR` to capture a new reference. Keep the reference directory
separate from the new capture, and use the same source path for comparisons.

The Metal runner requests `-std=macos-metal2.0 -mmacosx-version-min=13.0`, removes only
its own named outputs, requires successful compilation and linking with nonempty
artifacts, and requires the invalid probe's deliberate diagnostic. Never
substitute a newer or unversioned standard.
Probes cover both stages, user varyings, float4 buffer slots, 2D and cube resource
helpers, explicit vertex/cube LOD, flat integers, depth, and thread references.
These are hand-authored syntax probes, not cgc-generated output or GPU tests.
